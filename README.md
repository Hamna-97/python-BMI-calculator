# BMI Calculator 

A simple **Body Mass Index (BMI) Calculator** built using Python. This beginner-friendly project calculates a user's BMI based on their weight and height and displays their BMI score along with its corresponding category.

##  About the Project

The BMI Calculator asks the user to enter their weight in kilograms (kg) and height in centimetres (cm).

The program then:
- Takes weight and height as input from the user.
- Converts height from centimetres to metres.
- Calculates the user's BMI score.
- Displays the calculated BMI score up to two decimal places.
- Identifies the BMI category using conditional statements.
- Checks whether the entered height is valid.

##  BMI Formula

BMI is calculated using the following formula:

**BMI = Weight (kg) / Height (m)²**
